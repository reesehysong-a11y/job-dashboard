## 🌟 공공기관·출연연 특화 기능

### 1. 🏛️ 잡알리오 & 출연연 채용공고 스마트 크롤링
- **잡알리오 URL 원클릭 분석**: `job.alio.go.kr` 공고 링크를 입력하면 기관명, 채용분야, 고용형태(정규직/원급 연구원), 마감일시(18:00 정밀인식)를 자동 추출
- **한글(HWP) / PDF 공고문 붙여넣기 지원**: 공공기관 특유의 첨부파일 공고문이나 채용 사이트 본문을 복사(Ctrl+C)하여 붙여넣으면 Gemini AI가 즉시 정형화된 JSON 데이터로 변환
- **원클릭 포털 바로가기**: 상단 툴바에서 잡알리오, NIA, KIRO, RIST 채용안내 페이지로 1초 만에 이동

### 2. 📝 NCS 자기소개서 & 직무수행계획서 작성실
- **직무수행계획서 템플릿 내장**: 원클릭으로 [추진목표 - 세부추진전략 - 기대효과] 표준 양식 자동 삽입
- **경험/경력기술서 STAR 기법 템플릿**: [Situation - Task - Action - Result] 구조 자동 삽입
- **엄격한 바이트(Byte) & 글자 수 실시간 계측**:
  - 공백 포함 / 공백 제외 글자 수
  - **바이트(Byte) 수 (EUC-KR/UTF-8)**: 공공기관 원서 접수 시스템의 글자 수 초과로 인한 실격 원천 방지
- **⚠️ 블라인드 채용 가이드 알림**: 학교명, 출신지역, 가족관계, 성별, 나이 기재 금지 주의사항 안내

### 3. 📋 공공기관 필수 제출 서류 체크리스트
- NCS 입사지원서
- 직무수행계획서 / 연구수행계획서
- 연구실적목록 (논문 첫 페이지, 특허등록원부 PDF)
- 공인영어성적 증명서 (TOEIC/TOEFL 기준 점수)
- 블라인드 채용 확인서 및 개인정보 동의서

### 4. 📅 전형 단계별 캘린더 & D-Day 알림
- 공공기관 특화 전형 단계: `서류 준비` ➡️ `접수 완료` ➡️ `서류 합격` ➡️ `필기전형 (NCS/전공)` ➡️ `1차 직무/PT 면접` ➡️ `2차 종합 면접` ➡️ `최종 합격`
- **.ics 캘린더 연동**: 마감 1일 전 및 3시간 전 Mac/아이폰/구글 캘린더 알림 발송
